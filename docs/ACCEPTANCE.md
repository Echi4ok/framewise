# Проверка требований

6 ноября выполнено повторное архитектурное ревью с исправлениями и UI smoke на локальной модели: 84 backend и 48 frontend тестов, lint/typecheck/build проходят. Подробности и ограничения проверки Docker находятся в [RUN_VERIFICATION.md](RUN_VERIFICATION.md). Таблица ниже сохраняет исходную оценку требований и качества модели от 5 ноября.

Проверено 5 ноября 2026 года, Europe/Moscow. Источник — `testovoe_ai_engineer_final.pdf`, страницы 1–3. `passed` относится к указанному сценарию. `quality limited` отмечает найденные ошибки содержания или локализации. `partial coverage` означает, что часть ветвей не проверялась в реальном UI.

Backend-тесты используют подменённый VLM API. Native/Docker-прогоны и браузерные сценарии выполнены с настоящей Qwen3-VL. Валидный JSON и допустимая геометрия не подтверждают истинность текста или точность рамки.

В сравнении v3 без каталога у 8B совместно подтверждены текст, рамка и физическая деталь для 10/17 признаков, без повторов — 9/17. Это выбранный development set, использованный для настройки. Финальное приложение дополнительно передаёт название как ориентир. Эти числа не являются измерением финальной name-only конфигурации на независимой выборке. [Протокол](RESEARCH.md), [ручные метки](../evaluation/manual-review.json).
